# govil.ai motion graphics (9:16, Hebrew, silent)

20 vertical videos (1080×1920, 30fps, H.264) for Reels / TikTok / Shorts.
Everything is code: edit a scene, re-render it. Numbers and dataset titles come from the real
published manifest, never typed by hand.

## Layout

| Path                           | What                                                                                            |
| ------------------------------ | ----------------------------------------------------------------------------------------------- |
| `engine/`                      | Seekable timeline engine (`engine.js`), brand CSS/tokens (`engine.css`), player page            |
| `scenes/NN-name.js`            | One video each. `export const duration` + `export default (E) => {…}`                           |
| `scenes/_kit.js`, `_sector.js` | Shared pieces: CTA card, dataset card, illustrative motifs, sector template                     |
| `data/stats.json`              | Real figures, generated by `scripts/extract-stats.py` from `frontend/public/data/manifest.json` |
| `assets/fonts/`                | Rubik (same files as the site)                                                                  |
| `render.mjs`                   | Headless Chrome → frames → ffmpeg                                                               |
| `out/`                         | Rendered MP4s + stills (gitignored)                                                             |

## Commands

```bash
cd motion && npm install                       # once (puppeteer-core; uses /usr/bin/google-chrome)
python3 scripts/extract-stats.py               # refresh numbers from the manifest
node render.mjs 10-transport                   # render one video -> out/10-transport.mp4
node render.mjs all --jobs 4                   # render everything
node render.mjs 10-transport --stills 1,5,9    # PNG stills at those seconds (fast layout check)
scripts/sheet.sh 10-transport 6                # contact sheet of the stills
```

`CHROME=/path/to/chrome` overrides the browser.

## Editing a video

- **Copy / timing:** open the scene file; times are seconds, `s = E.seg(start, dur, {bg})`
  makes a full-screen segment (`blue | ink | light | white`), helpers inside take _segment-local_ seconds.
- `*word*` in text highlights it in the accent color. `s.words()` reveals word by word.
- Sector videos (10–17) are 8 lines each: change `hook`, `picks` (indices into the sector's top
  datasets in `stats.json`), `questions`, CTA. Length `S` = 20s, `L` = 50s (`_sector.js`).
- Determinism: never use `Math.random` or `Date`; use `E.rng(seed)`. Animations are paused Web
  Animations driven by `E.seek(t)`, so every frame is reproducible.
- Illustrative visuals (generic chart shapes, map pins) are labelled "איור להמחשה בלבד" — keep that
  label when adding new ones; real figures only come from `stats`.

## Audio

Hebrew voiceover (Microsoft Edge neural TTS via `edge-tts`; clips cached in `data/tts/`), a quiet music bed
that ducks under the voice (synthesized with numpy, no samples/licensing), and only two soft effects
(scene-change swish, confetti sparkle).

- **What the narrator says:** `scripts/narration.py`. Each line is `(segment_index, offset_s, text)`, anchored to
  segment starts from the engine's cue file, so narration follows timing edits. Lines never overlap (a long line
  pushes the next one back) and are sped up to 1.28x at most; the script prints `DRIFT` if a line runs late.
- **Voice:** `VOICE=he-IL-AvriNeural` for the male voice (default `he-IL-HilaNeural`); `TTS_RATE=+4%` to adjust speed.
- Spell the brand phonetically in narration (`BRAND`), digits are fine for numbers.

```bash
cd motion && python3 -m venv .venv-tts && .venv-tts/bin/pip install edge-tts numpy   # once
node events.mjs all                                   # record cue timelines -> data/events/*.json
.venv-tts/bin/python scripts/make_audio.py all        # voice + music + mux -> out/NN-name.mp4
.venv-tts/bin/python scripts/make_audio.py 10-transport --no-voice   # music-only variant
```

Full rebuild of one video: `node events.mjs X && node render.mjs X && .venv-tts/bin/python scripts/make_audio.py X`
(silent video stays in `out/silent/`). Output is normalized to about -14 LUFS with a -3 dBFS ceiling.

## Numbers

`scripts/extract-stats.py` reads the live `https://govil.ai/data/manifest.json` (use `--local` for the
repo copy). Re-run it, then re-render, to refresh every figure.
